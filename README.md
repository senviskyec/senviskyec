### Calamity Mod Weapon Effectiveness Model *(Python)*
Data-driven model for evaluating and predicting weapon effectiveness across progression in the Terraria Calamity mod. Built two Scrapy spiders to collect weapon and enemy/boss datasets from the Calamity wiki — attributes include damage, use time, critical chance, rarity, health, defense, and attack damage. Cleaned and normalized the data with Pandas, including numeric extraction and feature engineering.

The model scores weapons using a weighted combination of normalized DPS, base damage, attack speed, rarity, knockback, critical chance, and use time. A key challenge was constraining recommendations to weapons actually available at a given progression stage. Weapons are first bucketed by stage (Pre-Hardmode, Hardmode, Post-Moonlord), then tiered within each stage based on the number of bosses present. DPS calculations incorporate enemy defense values scraped from the Bestiary page, which penalizes low-damage, high-speed weapons against high-defense enemies and better reflects real gameplay. Final rankings closely align with popular class progression guides.
> `Python` `Scrapy` `Pandas` `Web Scraping` `Data Modeling` `Feature Engineering`
